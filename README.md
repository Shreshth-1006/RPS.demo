# 🪨 Rock Paper Scissors Game

A simple **Rock Paper Scissors** game built using **Python** and **Streamlit**. Play against the computer and see the result instantly through an easy-to-use web interface.

## Features
- 🎮 Play Rock, Paper, or Scissors
- 🤖 Random computer choice
- ⚡ Instant win, lose, or draw result
- 🌐 Simple Streamlit web interface

## Technologies Used
- Python
- Streamlit

## Run Locally

1. Install the required package:
```bash
pip install streamlit
```

2. Run the app:
```bash
streamlit run app.py
```

Enjoy the game! 🎉
